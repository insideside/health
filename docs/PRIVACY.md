# Тренер — приватность: что куда уходит

Коротко: **все данные живут на этом компьютере** (`data/trainer.db`), локальная ИИ работает на нём же, в интернет
сервер сам ходит только за двумя вещами — поиском продукта в Open Food Facts (уходит только название продукта) и
погодой Open-Meteo (уходят только координаты города из профиля). Оба выключаются. Что видит партнёр и попадает ли ваша статистика в общие выводы — решает каждый сам.

Аудит проведён по коду 2026-09-28 (`grep` всех сетевых вызовов: `httpx`, `urllib`, `fetch`, `socket`, `subprocess`).

## Исходящие соединения сервера

| Куда | Кто | Что уходит | Как выключить |
|---|---|---|---|
| `http://127.0.0.1:11434` (Ollama) | `app/ai/ollama.py` | промпт и данные для ответа ИИ (еда, профиль, статистика) | — это локальная модель на этом же компьютере |
| `world.openfoodfacts.org`, `search.openfoodfacts.org` | `app/ai/jobs.py → off_search()` (задача `foodlookup`, кнопка «Найти с ИИ» в справочнике продуктов) | **только название продукта** из поля поиска (без слов о состоянии), заголовок `User-Agent: Trainer/1.0`. Ни логина, ни id, ни записей | Профиль → «Данные и приватность» → «Искать продукты в интернете» (настройка сервера `meta.web_lookup`), или жёстко — переменная окружения `TRAINER_NO_WEB=1` при запуске |
| `api.open-meteo.com`, `geocoding-api.open-meteo.com` | `app/weather.py` (погода на «Сегодня», поиск города в профиле) | **только координаты города** из профиля (округлены до 0,01°) или строка поиска города; `User-Agent: Trainer/1.0`. Ни имени, ни id, ни записей. Ответ кэшируется на час | Профиль → «Данные и приватность» → «Погода для „Сегодня“» (настройка сервера `meta.weather`), или `TRAINER_NO_WEB=1` |
| Cloudflare (`cloudflared`), если включён доступ из интернета | `app/wan.py` | туннель к HTTPS-порту сервера: трафик ваших же устройств идёт через Cloudflare (внутри — HTTPS до `trycloudflare.com`) | по умолчанию выключено; Профиль → «Приложение» → доступ из интернета |

Больше сервер никуда не обращается: нет аналитики, телеметрии, шрифтов и скриптов с чужих CDN (всё в `app/static/`),
нет проверки обновлений. `certs.py` вызывает только локальные `ifconfig` и `scutil` (узнать свои IP и имя в сети).

**Ollama только локально.** Адрес по умолчанию `http://127.0.0.1:11434`. Его можно переопределить переменной
`OLLAMA_URL`, но только на этот же компьютер: если там окажется не `127.0.0.1`/`localhost`/`::1`, сервер
**не запустится** (`app/ai/ollama.py`) — личные данные не могут уйти в чужую модель даже по ошибке в настройках.
Переключатель поиска продуктов в интернете меняет только владелец сервера или человек за этим компьютером. Сама Ollama (`brew services`) данные в сеть не отправляет;
модель скачивается один раз командой `ollama pull`.

## Клиент (PWA)

Страница ходит только на свой сервер (`/api/*`, адреса-зеркала этого же сервера). Service Worker кэширует оболочку,
данные — в IndexedDB устройства. Сторонних запросов нет.

## Что видят другие люди на сервере

| Кто | Что |
|---|---|
| Партнёр | только `PUBLIC_KINDS = ("dsum", "ach", "wsum")`: оценка и % дня, опыт, достижения, оценка недели. Шаги, сон, активность — **только** если вы включили «Соревнование» и выбрали эти категории (`profile.compete.show`). **Питание, вес, замеры, сон по умолчанию, заметки, чат — никогда** |
| Все устройства (общая «память тренера») | обезличенные знания: «тарелка борща» → продукт и граммы, синонимы, порции. Без id людей, имён и заметок |
| Общая статистика «что на что влияет» | только если вы включили «Делиться обезличенной статистикой» (`profile.share_stats`, по умолчанию **выкл.**), и только средние по группе от 3 человек |

### Память тренера (`knowledge`)

Хранит только впечатление о еде и активностях, не о людях. Фраза попадает в память, если каждое её слово — слово
о еде: из справочника продуктов, единица, посуда, число, предлог, слово состояния (`brain.impersonal()`).
«тарелка борща», «кружка какао с зефирками» — попадут; «борщ у мамы Иры», «обед с коллегами» — нет.
Кто научил знанию, не записывается (только источник: `ai` / `user` / `stats`).

### Статистика (`outcomes`)

Недельные строки «сон, шаги, тренировки, белок г/кг, калории от нормы, активность, читмилы, поздняя еда →
изменение веса, талии, руки, оценка недели» с типом человека (пол, возрастная группа, телосложение, главная цель,
активность). Вместо id — псевдоним (`sha256(соль сервера + id)`), соль хранится только на сервере. Таблица
пересобирается кодом из ваших записей (без ИИ), не чаще раза в 6 часов или по кнопке.
Наружу (`GET /api/brain/insights`) отдаются: ваши собственные связи и **агрегаты** по группам, где не меньше
3 человек, согласившихся делиться. Сырые строки других людей не отдаются никогда. Сравнение с другими видит
только тот, кто сам делится. Выключили — со следующей пересборки ваши недели в общих выводах не участвуют.

## Где это в коде

- `app/brain.py` — память знаний, статистика, настройки `web_lookup`, проверка адреса Ollama.
- `app/ai/jobs.py → off_search()` — поиск продукта в интернете; проверяет `brain.web_allowed()`.
- `app/weather.py` — погода и поиск города (Open-Meteo); проверяет `weather.allowed()`.
- `app/db.py → PUBLIC_KINDS`, `app/sync.py → changes_for()` — что синхронизируется партнёру.
- `app/static/brain.js → privacyBody()` — раздел профиля «Данные и приватность».
