# «Здоровье» → Тренер через Команды iOS

PWA не имеет доступа к HealthKit — это ограничение iOS. Данные из «Здоровья» приносит в Тренер
команда на iPhone: она читает образцы и отправляет их POST-запросом на сервер с личным токеном.
Сервер: `POST /api/health/import` (см. [V2-CONTRACTS.md](V2-CONTRACTS.md)).

**Каждый настраивает команду на своём iPhone и со своим токеном** — тогда данные попадают в свой аккаунт.
Токен привязан к аккаунту, а не к устройству; он даёт право только на импорт, больше ничего.

## 1. Взять токен

Тренер → Профиль → «Здоровье iPhone» → «Показать токен» (`GET /api/health/token`).
Если токен утёк — там же «Выпустить новый» (`POST /api/health/token`), старый перестанет работать,
и его нужно заменить в команде.

Адрес сервера — тот же, что открыт в Safari, например `https://имя-компьютера.local:8790`.
Сертификат Тренера должен быть установлен и включён в «Доверии сертификатам» (как для самого приложения),
иначе команда не сможет отправить запрос.

## 2. Собрать команду «Тренер: Здоровье»

Приложение «Команды» → «+» → назвать «Тренер: Здоровье». Добавить действия по порядку.

**Шаги за сегодня**
1. «Найти образцы Здоровья»: Тип — *Шаги*; Начальная дата — *сегодня*; Группировать по — *День*;
   Сортировать — нет; Ограничение — выкл.
2. «Вычислить статистику» → *Сумма* по результату (или сразу «Сумма» в самом действии, если оно есть в вашей версии iOS).
3. «Задать переменную» `steps`.

**Сон прошлой ночью**
4. «Найти образцы Здоровья»: Тип — *Анализ сна*; Начальная дата — *за последние 1 день*;
   Значение — *Во сне* (или «Сон: основной/глубокий/REM», если выбор есть).
   Сортировать по — *Дата начала*, по возрастанию.
5. «Получить сведения об образцах Здоровья» → *Дата начала* → «Получить объект из списка» → *Первый объект* →
   «Форматировать дату» (формат ISO 8601) → переменная `bed`.
6. То же с *Дата окончания* → *Последний объект* → ISO 8601 → переменная `wake`.

**Вес (последний)**
7. «Найти образцы Здоровья»: Тип — *Вес*; Сортировать — *Дата начала*, *сначала новые*; Ограничение — *1*.
8. «Получить сведения об образцах Здоровья» → *Значение* → переменная `weight`
   (единицы — килограммы; если в «Здоровье» фунты, поменяйте единицу в «Здоровье» или в действии).

**Активные калории за сегодня**
9. «Найти образцы Здоровья»: Тип — *Активная энергия*; Начальная дата — *сегодня* → «Сумма» → переменная `active_kcal`.

**Тренировки за сегодня — с пульсом**
10. «Найти образцы Здоровья»: Тип — *Тренировки*; Начальная дата — *сегодня*.
11. «Повторить с каждым», внутри:
    - «Найти образцы Здоровья»: Тип — *Частота пульса*; с *Даты начала* по *Дату окончания* текущей тренировки →
      «Получить сведения об образцах» → *Значение* → переменная `hr` (список замеров);
    - «Словарь» с ключами `type` (*Тип тренировки*), `start` (*Дата начала*), `end` (*Дата окончания*),
      `kcal` (*Активная энергия*), `distance` (*Дистанция*, если есть), `heart_rate` = `hr`;
    - «Добавить в переменную» `workouts`.
    Вместо списка замеров можно прислать готовые `hr_avg` / `hr_max` / `hr_min`.

**Пульс в покое и вариабельность (HRV)**
12. «Найти образцы Здоровья»: Тип — *Пульс в состоянии покоя*; сначала новые; ограничение *1* → *Значение* → `resting_hr`.
13. То же с типом *Вариабельность пульса* → `hrv` (в миллисекундах).

**Цикл (по желанию)** — если цикл ведётся в трекере (Period Tracker by GP Apps, «Календарь месячных», Flo, Clue…),
в самом трекере включите синхронизацию с «Здоровьем».
14. «Найти образцы Здоровья»: Тип — *Менструации*; за последние *90 дней*.
15. «Повторить с каждым»: «Словарь» `date` (*Дата начала*), `flow` (*Значение*) → «Добавить в переменную» `period`.
Сервер найдёт начала циклов (перерыв ≥ 3 дней), медианную длину цикла и месячных и обновит `profile.cycle`.

**Отправка**
12. «Текущая дата» → «Форматировать дату»: *Пользовательский* `yyyy-MM-dd` → переменная `date`.
13. «Получить содержимое URL»:
    - URL: `https://<имя-мака>.local:8790/api/health/import`
    - Метод: **POST**
    - Заголовки: `X-Trainer-Token` = ваш токен
    - Тело запроса: **JSON** с полями `date` (текст), `steps` (число), `weight` (число), `active_kcal` (число),
      `sleep` (словарь: `bed` = переменная bed, `wake` = переменная wake), `workouts` (переменная workouts),
      `resting_hr`, `hrv`, `period`.
14. (по желанию) «Показать уведомление» с результатом — сервер отвечает `{"ok": true, "imported": {…}}`,
    там видно, что именно записалось.

Сервер терпим к особенностям Команд: числа можно слать текстом и с запятой («88,4»), значения — списками
(шаги по часам сложатся), даты — ISO или «дд.мм.гггг», сон — либо `{bed, wake}`, либо списком интервалов
`[{start, end}]`, английские и русские названия тренировок (неизвестные запишутся как «другое» с исходным названием).

## 3. Запускать автоматически

Команды → «Автоматизация» → «+» → «Создать автоматизацию для себя»:
- **Время суток**, например 22:30 ежедневно → действие «Запустить команду» → «Тренер: Здоровье»;
  выключить «Спрашивать до запуска» (иначе придётся подтверждать каждый раз);
- по желанию — вторая автоматизация «Приложение» → «Открыто» → Тренер (данные подтянутся при каждом открытии).

Запускать можно сколько угодно раз в день: импорт по дате идемпотентен (записи перезаписываются, не множатся).

## Что и куда записывается

| Данные | Куда | Правило |
|---|---|---|
| шаги | отметка пункта чек-листа «Шаги» за день | перезаписывается при каждом импорте |
| активные калории | в ту же отметку, поле `active_kcal` | для отчётов |
| сон | запись сна за день пробуждения | **только если вы не внесли сон вручную** — ручная запись точнее |
| вес | замер за день | только если за этот день веса ещё нет |
| тренировки | активности с пометкой «из Здоровья»: время, дистанция, пульс (сред./макс./мин.) | вид — по названию; интенсивность — по среднему пульсу: зоны 64 % / 77 % от максимума 208 − 0,7·возраст |
| пульс в покое, HRV, VO₂max | `vitals:{uid}:{дата}` — только владельцу | «готовность» снижается, если пульс в покое выше обычного (медиана за 21 день) на 4–7+ или HRV ниже на 12–25 % |

## Ограничения (проверьте на своём устройстве)

- **Данные супруга через «Здоровье → Общий доступ»**, по нашим данным, Командам недоступны: «Найти образцы Здоровья»
  читает только собственные данные телефона. Проверьте у себя; надёжный путь — отдельная команда на телефоне
  каждого со своим токеном.
- **На компьютере** «Здоровья» нет (на Windows и Linux вовсе, на Mac сторонним программам оно данные не отдаёт) —
  поэтому импорт идёт только с iPhone.
- Названия действий и полей в Командах немного отличаются между версиями iOS; ищите по смыслу.
